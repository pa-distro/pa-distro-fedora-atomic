========================================
  Benvenuto/a nella postazione PA (KDE)
========================================

Questa è una postazione dimostrativa basata su Fedora Kinoite (KDE Plasma).

App principali già installate:
  - LibreOffice (Writer / Calc / Impress)
  - Thunderbird (mail e PEC)
  - Firefox (browser)
  - Okular (PDF, con firma)

Per l'aiuto e le guide passo-passo apri l'app "Guida PA" dal menu.

Regole rapide:
  - Non installare software da fonti non approvate.
  - Non modificare il sistema (rpm-ostree / bootc): è immutabile.
  - Se un programma si blocca: "Attendi" o "Termina".
  - Per problemi, contatta il tecnico dell'ufficio.
